# softplc
Thesis work of softplc implementation including tree structure and code for measurements. 

The stoppermeasurement.project is a CODESYS file for CODESYS v3.5 SP21 PATCH 5 for measuring stopper latency with the help of a confirmation sensor (BG9). It includes the tree structure and code for this specific setup.
The python file is all our samples for both the traditional and software PLC and code for plotting them in the same window.
